# How to run the code

This script runs time-resolved decoding analysis for one dataset at a time.

## Required input files

Place the `.mat` files inside the `svm_data/` folder.

For a dataset name such as `M2_mSTS`, the script expects:

- `svm_data/M2_mSTS_all_data_res_window_bins_18_TD.mat`
- `svm_data/M2_mSTS_all_data_res_window_bins_18_PC.mat`

## Install required packages

python Exp2_bins_MP.py --data_name DATA_NAME --num_iterations N

Example commands (Run 10 iterations for M2_mSTS) M2 = Monkey name , mSTS = Region

python Exp2_bins_MP.py --data_name M2_mSTS --num_iterations 10
